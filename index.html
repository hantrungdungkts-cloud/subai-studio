Cài Đặt Whisper AI (Chạy Trên Trình Duyệt)

Ứng dụng chạy mô hình Whisper AI trực tiếp trên thiết bị của bạn (không cần API Key, không cần máy chủ, hoàn toàn miễn phí).

Tạo Key miễn phí tại console.groq.com/keys. App tự động cắt bỏ khoảng lặng để tiết kiệm 30–50% lượt dùng Groq.

Nếu Groq hết lượt theo giờ/ngày, App tự động chuyển sang Gemini Flash miễn phí (hoặc chạy AI ngay trên máy).

📁 Dự Án Đã Lưu Trên Phần Mềm

Tất cả video và phụ đề được lưu trực tiếp trên máy chủ. Bạn có thể mở lại bất cứ lúc nào để xem, sửa tiếp hoặc xuất video mà không cần tải file về.

Xuất & Nhập File Phụ Đề

1. Xuất file phụ đề (.SRT / .VTT / .ASS)

Tải xuống ngay lập tức để dùng trên YouTube, CapCut, VLC hoặc trình phát video.

2. Nhập file phụ đề có sẵn (.SRT / .VTT)

Mở file phụ đề sẵn có từ điện thoại / máy tính để chỉnh sửa, đổi kiểu chữ hoặc dịch sang ngôn ngữ khác.
